# ZipRocket — Frontend Client (Next.js PWA)

This directory contains the Next.js 16 Progressive Web App (PWA) client for ZipRocket.

For complete fullstack system documentation, architecture diagrams, API specifications, and environment configuration, please refer to the [Root README.md](../README.md).

### Quick Start (Client Only)

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
